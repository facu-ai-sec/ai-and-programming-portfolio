# Discord Webhook Messenger

Python script that sends a message to a Discord channel using a webhook URL and the requests library.



## Features

- Sends messages to a Discord channel via webhook
- Uses HTTP POST requests
- Handles basic response status validation
- Simple and readable code structure

## Technologies

- Python
- requests

## How it works

1. Prompts the user to enter a message  
2. Sends the message to the Discord webhook URL  
3. Checks the HTTP response status  
4. Prints a success or error message

## Configuration

The script can be configured by modifying the constant at the top of the file:

- Discord webhook URL

## Usage

```bash
